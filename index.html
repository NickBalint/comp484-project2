    Debug JavaScript Bug

    This mini calculator intentionally starts with a bug similar to the DevTools tutorial. It concatenates strings instead of adding numbers.

    5 + 1 = 51 (buggy mode)

    1. Reproduce bug with inputs 5 and 1.
    2. Open Sources, set breakpoints in runBuggyCalculator and computeSum.
    3. Inspect values in Scope, add watch expression typeof sum.
    4. Use Console while paused to evaluate parseInt(addend1) + parseInt(addend2).
    5. Click Apply Fix and verify output changes to numeric addition.
